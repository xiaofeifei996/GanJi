# GanJi — 全国行政区划数据加载

## 照片日历小组件（1.5.0，build 50）

重做小、中、大三套布局：小号突出今日日期和圩名；中号左侧今日、右侧明后天；大号以照片留白和三日纵向日程呈现。默认使用深青渐变背景，白色文字、轻量半透明日程面板，每天提供完整圩名的 VoiceOver 描述。

主页右上角「小组件」打开外观设置。三种尺寸分别选择照片，可调整水平/垂直取景和压暗程度，实时预览与扩展共用实际 SwiftUI 布局。保存或恢复默认后请求刷新时间线。系统照片选择器只读取选中的图片，不申请整个相册访问权限。

图片先降采样、校正 EXIF 方向，再按尺寸裁剪；照片与遮罩配置作为原子记录写入共享目录，读取最新有效记录。恢复默认写入清除标记，防止旧备用文件把照片恢复回来。共享路径不可写时明确报错；侧载签名仍需有效 App Group 或支持现有目录权限的安装环境。

背景通过 iOS 17+ 的 `containerBackground(for: .widget)` 声明。系统染色、透明等外观可能隐藏或改变照片；查看原图请使用全彩外观。无背景时文字和面板适配系统颜色。

扩展一次生成七天时间线，后续条目从本地零点开始，重叠日期的排期只计算一次。系统仍负责实际展示和调度；收藏变化会请求重新加载时间线。

快照读取会验证全部存储通道并选择最新的有效收藏快照；损坏、旧格式文件不再挡住有效备用数据。写入回读必须与本次写入一致。回归测试覆盖快照回退、清空收藏、跨年、23/25 小时夏令时日期及无数据状态。

CI 运行排期与上述回归测试，再构建主 App 和扩展。优化分支提供独立 IPA artifact，只有 main 分支更新 nightly。系统染色、透明外观及实际布局仍需真机验收。

**数据源只有收藏**：小组件显示的是 App 里点心形收藏的圩点，不是当前地区的全部圩日，
所以收藏可以跨地区。`Shared/WidgetFeed.swift` 定义 `MarketRule`（id/名称/地区/圩期规则）与 `MarketSchedule`（地支三组相位 + 农历日匹配），
App 侧 `GanJi/WidgetFeeder.swift` 把收藏压成快照写入 App Group 的 `GanJiWidgetFeedV1`，
扩展侧 `Widget/WidgetProvider.swift` 读取并生成七日版面。只传规则，不传坐标、地址或任何图片。

快照带 `source` 字段标记来源；1.4.0 写过「全区圩点」的旧快照会被识别并丢弃，
避免升级后突然显示一堆没收藏过的圩。收藏增删会立即触发 `reloadAllTimelines()`。

空状态分两种：从未同步过显示「尚未同步」，同步了但没有收藏显示「还没有收藏」。

**兼容性**：`data`/`region.json` 未改动；`MarketStore` 保持原样，`Shared/MarketData.swift` 的 `opens(on:)` 仍未被使用，留作通用工具。

## 当前变更：移除硬编码地区备用项

- 删除 `regionOptions` 中的 6 条广西县级地区硬编码数据，以及由它们推导省、市记录的逻辑。
- 地区搜索与省、市、区县选择器现在只使用成功加载的 `nationalRegionOptions`。
- 保留 MapKit 地点结果匹配逻辑；该逻辑用于处理地址字段不完整的情况，不是硬编码地区数据。
- `Shared/regions.json` 文件暂时保留，但当前地区加载代码没有读取它，因此它不会作为运行时备用地区列表。

验证：已完成源码检查与 ZIP 完整性检查；尚未通过 Xcode 或 iPhone 进行运行验证。


## v118 全国县区行政区划加载

- 行政区划优先从民政部国家地名信息库接口加载。
- 官方服务不可用时，尝试从 `province-city-china` 公共数据集加载全国省、市、县区层级数据。
- 加载时会校验县区条目数量（至少 2,500 条），避免误把不完整响应当作全国数据。
- 当前地区加载代码不读取 `Shared/regions.json`；首次完整加载需要网络。
- 行政区划覆盖不等于圩日 API 覆盖，圩日记录仍以接口实际返回为准。
